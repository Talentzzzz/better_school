# 01: 帖子审核新语义——先审后发 + 同步初筛报错 + 审核轮次

**What to build:** 用户发帖命中敏感词时立即收到报错、内容不落库（与商品/跑腿的同步初筛语义一致）；通过初筛的帖子一律落库为待审、进入统一人工裁决入口，审核通过才对他人可见，拒绝为终态（本票不含转草稿）。发布即审（轮次 1），审核队列中帖子按业务表审核轮次取数，不再恒为一；审核记录按目标+动作+轮次幂等。搜索维持仅同步可见态帖子。

**Blocked by:** None (can start immediately)

**Status:** ready-for-human

- [x] 发帖命中敏感词：报错"内容包含违规词汇，请修改后重试"，数据库无该帖
- [x] 通过初筛的帖子落库即待审，他人不可见；作者可见自己的待审帖
- [x] 人工裁决通过 → 可见并同步进搜索；拒绝 → 终态、理由必填、不同步搜索
