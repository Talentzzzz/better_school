# 01: 信息流分隔与卡片规范

**Spec:** `.scratch/ui-revamp/spec.md` §「信息流分隔与卡片规范」（spec 索引 ①）

**What to build:** 首页发现与市集跑腿、市集闲置三处信息流统一改成同一套分隔与卡面：页面底色转浅灰 `#f2f2f5`，卡片为白底、圆角 12、带阴影、内边距 8，列间距与行间距都收到 8，图片统一 1:1 裁剪（不再按原图比例错落）。帖子无封面卡换成柔和渐变卡面，**摘要在上、标题在底部**，meta 行落在卡内；有封面帖为 封面图 → 标题 → meta。闲置卡出价格行（`¥` 金额 + 成色），跑腿卡无图、出类型 badge + 悬赏 + 路线块。色值与字号一律以 spec 表格为准。

这是后续 04（作者主页笔记/赞过复用此卡面）、06（求购卡沿用此规范）的基准，先落。

## 实现要点（票 01）

- **令牌与共享类**（`variables.scss` / `common.scss`）：新增 `$bg-page-alt`(#f2f2f5)、`$radius-card`(12px)、`$shadow-card`；抽取共享类 `.feed-card`（卡片外壳 = padding 8 / 圆角 12 / 白底 / 阴影 / 按下态 `#fafafa`）与 `.feed-thumb`（图片圆角 8 + 裁切）——**票 04/06 直接复用这两个类与令牌，不要再各写一份外壳**；补 `.ellipsis-4`/`.ellipsis-5`（跑腿描述 4 行、无标题帖 lead 5 行）。
- **三张卡**：`PostCard`（有封面：1:1 图 → 标题 14/500/1.45 → meta；无封面：渐变卡面 `padding 14px 12px` + 摘要 12/1.55/#6b6b70 三行 → 标题 15/550 置底 → meta，无标题则摘要按 lead 14/$text-1 排五行、不渲染标题行；有封面无标题仍「（无标题）」）；`ProductCard`（1:1 图 → 标题 → 价格行 `¥` 15/700 `$primary` + 成色 10/400 `#999999` → meta「N 人想要」）；`ErrandCard`（无图；类型 badge `rgba(255,36,66,.1)` + 悬赏 13/700 → 描述 4 行 → 灰底路线块 `$bg-secondary`/圆角 6/`5px 7px`/11px → meta 时间；多人单「每人 ¥x」）。三处 `AppImage` 统一 `ratio="1:1"` 并去掉 `dynamic`（不再按原图比例错落）。
- **页面**：`HomeView`/`MarketView` 页面底色改 `$bg-page-alt`（两者 `.waterfall` 本就是列/行距 8 + 左右边距 8，未改）。
- **验收方式**：`npm run build`（vue-tsc）通过；Playwright 拦截 `/api` 回伪造数据，在 1280×900 与 390×844 两个视口目视 + 核对计算样式（页底 `#f2f2f5`、卡片白/圆角 12/阴影/padding 8、渐变 `linear-gradient(135deg,#f3f0ff,#eef4ff)`、悬赏 `¥6`/`每人 ¥8`/`¥10`、价格 15/700 红、成色 10/400 `#999999`、meta 10px `#999999`），截图存 `verify-01/`。
- **code-review 结果**：Spec 轴揪出 meta 右侧统计色原为 `$text-2`(#666666)、按 spec 与 D 原型应为 `#999999`——已随本票改回继承（仅 `.liked` 保持 `$primary`）；Standards 轴指出三张卡外壳逐字重复三份——已抽 `.feed-card`/`.feed-thumb`。
- **已知波及（不在本票范围）**：`SearchView` 与 `MyFavoritesView` 复用同一批卡片，现为「白卡落在白底页」（靠阴影分隔，页面底色未动）。spec §适用范围只列四处信息流，故本票不改这两页；是否也铺灰底待后续定。
