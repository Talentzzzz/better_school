## Notes

- **需求问题一律查 spec 对应章节**，本 effort 不重开设计讨论；发现 spec 缺口回 `errand-lock-review-hub` 补票。
- **拆票口径**（用户 2026-10-14 定）：14 张票，每票一个连贯行为、可独立验收；跑腿侧**本期只做后端 + 走通流程的最小接线**，草稿箱 / 锁单倒计时 / 确认放弃的**视觉细案**仍属 spec §9 开放项、另开 effort。
- **文档收口为单张终验票**（票 14），对齐 `project-rework` 票 18 先例。
- **迁移口径**：本仓无编号迁移脚本——DDL 只改 `backend/better-school/sql/schema.sql` 后重建库生效；若将来恢复编号迁移，从历史最大 **028** 续号。
- **超时中心零代码改动**：两个新 taskType（`ERRAND_LOCK_TIMEOUT` / `REVIEW_LEASE_TIMEOUT`）都是**新增接入方**，只回填文档。
- **判过但未采纳备选**：`TAKEN→CONFIRMED` 是一次机械化宽改名（blame 面铺全仓），但无存量数据、调用点由编译器与测试兜底，故不拆 expand–contract，收成票 01 一次落地。
- 领域词汇遵循仓库根 `CONTEXT.md`；后端分层与命名遵循 `backend/CLAUDE.md`；工程/部署细节不写进 `CONTEXT.md`。
- 前端无测试设施，验收靠 `npm run build`（`vue-tsc`）+ 浏览器目视；后端集成测试放 `bs-app/src/test`（连 `scripts/test-env.sh` 起的常驻栈）。
