# 06: 下架/到期汇入草稿箱 + 求购解冻 + 24h 待审超时提醒

**What to build:** 非终态停靠闭环与审核防遗忘。上架后的商品/求购可主动下架，直接进入草稿箱（与撤回、转草稿汇入同一状态），可重新提交；到期下架的定时任务（原"过期下架"）同样汇入草稿箱而非终态。求购的下架/到期必须**先解冻预算全额退回**再进草稿箱（预算仅在求购对外可见期间保持冻结——离开可见态一律解冻）；求购重新提交时重新走"待支付→支付（重新冻结）"。待审超 24h 未审的商品/求购，复用跑腿的超时扫描模式提醒管理员（收件人 ADMIN+AUDITOR，通知去重，绝不自动裁决）。

- [x] 商品上架后主动下架 → 进入草稿箱，可编辑后重新提交回待审
- [x] 求购上架后主动下架 → 预算全额解冻退回 + 进入草稿箱
- [x] 到期下架：商品进草稿箱；求购解冻退回预算后进草稿箱（不再进入任何终态）

- [x] 待审超 24h 未审（商品与求购）→ 管理员收到提醒，状态不变、绝不自动裁决
- [x] 提醒通知去重（同一条待审不重复轰炸）；下轮扫描补发吞掉的异常
- [x] 既有跑腿超时扫描行为无回归
