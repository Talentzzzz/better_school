# 05: 拒绝转草稿重提 + 编辑语义（改价 vs 改内容）

**What to build:** 商品被拒后的自救路径与上架后的编辑规则。商品：REJECTED 可转入草稿箱，修改后重新提交回到待审（产生第二次审核，审核记录由票 04 的轮次机制承接）。编辑语义：待审中不可编辑（撤回转草稿，票 02 已覆盖）；商品上架后改价格直接生效、不进审核，改标题/描述/图片则重新进入待审（期间对他人隐藏，不保留旧版展示，卖家本人可见），通过后恢复可见；求购上架后改标题/描述/图片同样回待审（**不重新支付**——首次发布已付），改预算 v1 明确不支持（引导下架重发）。商品与求购的改内容重审均不需要重新支付/重新初筛之外的额外环节。
