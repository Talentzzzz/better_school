# 移除项目全部审核(审核/举报/敏感词/先审后发)功能

## Context

用户要求去掉整个项目的所有审核部分。摸底发现审核是三层嵌套:
1. **独立审核机器**:ModerationController/ReviewController、工单池、举报、敏感词、/ws/review 推送、整个 front-review/ 审核台、6 个审核集成测试。
2. **先审后发/先审后售/先付后审**:post/product/errand 状态机内烧进 PENDING_REVIEW/REJECTED、review_round/review_entered_at 列、超时提醒、驳回理由链路。
3. **单调用方钩子**:举报→强制撤回/扣信用、AUDITOR 角色、AUDIT_* 通知类型、评论审核 MQ、发布流敏感词拦截。

用户拍板:**彻底移除**(发布即可见,状态字段一起删)、**敏感词一起去掉**、**先提交现有 WIP 再动删除**。完成后**不起环境跑测试**(编译 + test-compile 全绿即可,集成测试翻新到位不实跑)。

注意:工作区现有大量未提交 WIP(mapper 拆分 + Entity 命名重构,~90 文件),与本次删除混合;根目录的 review_tmp_diff.txt / review_diff*.txt / review_sqlmd.txt 是历史草稿,不提交不删动。
