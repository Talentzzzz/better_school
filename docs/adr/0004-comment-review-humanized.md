# 评论审核人工化（同步初筛 + 人工裁决）

ADR-0002 曾决定评论走"零同步初筛 + MQ 消费者自动裁决"，与帖子链路刻意不同。现决定全站内容（商品、求购、跑腿、帖子、评论）统一为同一审核口径：发布时同步敏感词初筛，命中即报错不落库；通过则落库为待审、进入人工裁决队列。评论原有的 outbox→MQ 消费者保留但降级为"通知审核员有新内容待审"，不再做任何裁决。

动机：让管理员对违规评论拥有裁决权（机器自动裁决时代人工无法干预），并消除"帖子有人审、评论机器审"的口径割裂。初筛已把明显违规挡在库外，发布路径的同步阻塞对评论这种碎片化内容可接受——单条评论重发成本极低，因此评论不需要草稿箱与重提（与帖子不同），被拒即终态、作者可见并带理由。

## Considered Options

- **维持 ADR-0002 自动裁决**：否决——人工把关缺口始终存在，机器初筛与人工裁决的口径不一致，未来接入 agent 自动裁决时也要重走此路。
- **去掉 MQ 链路、落库即待审**：否决——链路已存在，降级为通知的成本几乎为零，且审核员需要主动提醒（帖子侧无此链路，靠队列+超时扫描，属刻意的成本取舍）。

## Consequences

- 评论发布可能同步报错（初筛拦截），这是 ADR-0002 明确避免过的行为，现在被接受。
- 被拒评论从"彻底消失"改为"作者可见 + 理由可见"。
- 审核通过才计入评论总数、才发互动通知的口径不变。
