# Triage 标签

各 skill 以五个标准 triage 角色沟通；本仓库 tracker 直接用同名标签字符串（即 `Status:` 行的取值）：

| 标签               | 含义                           |
| ------------------ | ------------------------------ |
| `needs-triage`     | 维护者需要评估这个 issue       |
| `needs-info`       | 等待报告者补充信息             |
| `ready-for-agent`  | 已完整定义，可交给 AFK agent   |
| `ready-for-human`  | 需要人工实现                   |
| `wontfix`          | 不予处理                       |

skill 提到某个角色（如 "apply the AFK-ready triage label"）时，用上表对应的标签字符串。
