# 领域文档

探索代码库前先读：根目录 `CONTEXT.md`（领域词汇表）与 `docs/adr/` 里与改动区域相关的 ADR。文件不存在就静默继续，不标记缺失、不主动建议创建（`/domain-modeling` 会在术语或决策真正敲定时惰性创建）。

- **术语**：输出里（issue 标题、重构提案、假设、测试名）用 `CONTEXT.md` 定义的词，不漂移到它标 `_Avoid_` 的同义词。需要的概念不在表里时——要么你在发明项目不用的语言（收手），要么真有空缺（记下，交给 `/domain-modeling`）。
- **决策**：与现有 ADR 矛盾时显式指出，不静默覆盖：_与 ADR-0007 矛盾，但值得重谈，因为……_
- **布局**：本仓库是单上下文——根 `CONTEXT.md` + `docs/adr/`；出现 `CONTEXT-MAP.md` 才代表多上下文，那时读各上下文自己的 `CONTEXT.md` 与 `src/<context>/docs/adr/`。
